# umpire-latency-conflict-task

## Overview
This repository contains the experimental task code for the umpire latency conflict study.

## Usage / Notes
- **Main file**: `index.html.html`
- **Description**: [## Overview
This repository provides the experimental task code used to investigate human decision-making and cognitive control under latency conflicts in an umpire-style judgment paradigm.

## Key Features / Concept
- **Task Design**: Evaluates response conflict and cognitive load when task-relevant feedback or visual inputs are artificially delayed.
- **Goal**: Measures behavioral metrics (e.g., response time, accuracy, and error rates) across different latency conditions.
- **Environment**: Developed as a web-based task (`index.html.html`) for easy deployment in online/lab behavioral experiments.]
