# umpire-latency-conflict-task

## Overview
This repository contains an experimental task designed to investigate psychological load and cognitive conflict induced by feedback latency manipulation in an umpire-style decision-making paradigm.

## Experimental Concept & Mechanism
- **Feedback Asymmetry**: The task induces cognitive load by providing **immediate feedback for incorrect decisions** while **delaying feedback for correct decisions**.
- **Psychological Load & Conflict**: By systematically manipulating feedback timing based on decision accuracy, the task evaluates how selective delays generate psychological tension, influence conflict adaptation, and affect subsequent judgment performance in simulated umpire scenarios.

## Usage
- **Main Code**: Open `index.html.html` in a modern web browser to execute the experimental task.
